## הדרך היחידה היום: קונסולת Firebase

**החוקים אינם חלים על הקונסולה ועל ה-CLI**, ולכן משם אפשר.

⚠️⚠️ **ומחיקת מסמך הסלון אינה מוחקת את מה שבתוכו.** ב-Firestore אוספי משנה
אינם נמחקים עם המסמך שמעליהם. **החברים, עם המיילים שלהם, המשמרות, הקודים
והשורות שאינן נמחקות נשארים במסד** בלי סלון שמצביע עליהם, ואין מסך שמראה אותם.

**מחיקה מלאה היא מחיקה רקורסיבית:**

```bash
npx -y firebase-tools@14 firestore:delete branches/<מזהה-הסלון> --recursive --project hasalon-dev
```

⚠️ **ובלתי הפיכה.** אין גיבוי במוצר. **ואם הסלון היה אמיתי, היא מוחקת גם את
השורות שהמוצר מבטיח שאינן נמחקות**, רשומה
[29](29-nothing-records-that-someone-cancelled.md).

⚠️ **ולא נמדד:** האם מחיקה מתוך מסך הקונסולה מוחקת גם את אוספי המשנה. ה-CLI
עם `--recursive` הוא הדרך שידוע שמוחקת הכל.

  ודורש פונקציית ענן, כי דפדפן אינו יכול למחוק אוספי משנה ביעילות.
