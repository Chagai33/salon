# 23 — הייבוא עבר ל-Firebase, אחרי 504 ואחרי תיקון שגוי

> ✅ **סטטוס: נבנה, 06/10/2026. 15 בדיקות על הסינון, כולן עוברות.**
>
> ⚠️ **ועוד לא נפרס.** פונקציה אינה נפרסת מהקונסולה, והיא דורשת CLI פעם אחת.

## מה קרה, בסדר

**1. הייבוא נבנה כפונקציית Netlify**, כי האפליקציה נפרסת שם. ⚠️ **וזו הייתה
הכרעה בברירת מחדל ולא נימוק.**

**2. בעל המוצר העלה תמונה, וקיבל:**

```
המודל לא הצליח לקרוא את התמונה. נסו שוב בעוד רגע.
Failed to load resource: the server responded with a status of 504
```

**3. ⚠️⚠️ והתיקון הראשון שלי היה שגוי.** הנחתי שהתמונה כבדה, והוספתי הקטנה
ל-1200 פיקסל ונסיון חוזר ב-900.

**בעל המוצר עצר את זה במשפט אחד: "התמונה שוקלת 300 K."**

**והוא צדק.** 504 הוא `Gateway Timeout`, **ובגודל של 300 קילובייט ההעלאה אינה
הצוואר.** מה שלוקח זמן הוא המודל: לוח של שישה עשר ימים עם פלט מוטפס הוא
עשרות שניות, **ושער Netlify סוגר חיבור סינכרוני אחרי עשר שניות.**

⚠️ **והקטנה של התמונה הייתה גם מזיקה:** מה שצריך להישאר קריא הוא השעה, 19:00,
והיא הטקסט הקטן בלוח. **קידוד מחדש ב-0.85 פוגע בדיוק במה שצריך לקרוא.**

**4. ואז בעל המוצר שאל את השאלה הנכונה:** "ולמה העיבוד של התמונה או הפונקציה
עובדת ב-Netlify ולא בפיירבייס?"

## שלוש סיבות, ואחת מהן היא הכשל עצמו

| | Netlify | Firebase |
|---|---|---|
| ⚠️ **זמן ריצה** | **עשר שניות**, וזה ה-504 | **300 שניות** |
| זהות הקורא | ⚠️ ארבעים שורות שמאמתות חתימה ביד | `onCall` מעביר אותה |
| ⚠️⚠️ **בדיקה שהקורא מנהלת** | **בלתי אפשרית** בלי חשבון שירות | **נבדקת** |

⚠️ **והשורה השנייה אינה נוחות.** הקוד שכתבתי שם אימת חתימה מול התעודות
הציבוריות של גוגל, ו-**בדיקה אחת תפסה בו באג שהיה הורג את הפיצ'ר:**
`X509Certificate.publicKey` הוא כבר `KeyObject`, ולעטוף אותו ב-
`createPublicKey` זורק. **כלומר כל אסימון תקין היה נדחה.**

⚠️⚠️ **והשורה השלישית היא הפער האמיתי.** בגרסת Netlify כתוב בקוד במפורש:
"מה שהיא אינה בודקת: שהקורא הוא מנהלת." **כלומר כל חבר מאושר היה יכול לשרוף
את המכסה, וגם לקרוא לוח של סניף שאינו שלו.** בגרסה הזו:

```js
if (!snapshot.exists || member?.status !== 'active' || member?.role !== 'manager') {
  throw new HttpsError('permission-denied', 'notManager');
}
```

**הפונקציה אינה כותבת למסד.** היא מחזירה הצעה, המנהלת מסמנת, ורק אז נכתב.
`CLAUDE.md` אזור ליבה 4: **הייבוא כותב מידע על ימים אמיתיים.**

**וההנחיה למודל לא השתנתה**, כי היא נכתבה מתוך לוח אמיתי ולא מתוך הדמיון.
⚠️ **והשורה הנוקבת בה:** `access` הוא `unknown` כברירת מחדל. בלוח אירועים

שישי ושבת ומוחקת בשקט את כלל סוף השבוע.**

## ⚠️ ומה שנדרש מבעל המוצר

**1. המפתח ב-Secret Manager של Firebase**, ולא ב-Netlify:

```bash
npx firebase login
npx firebase functions:secrets:set GEMINI_API_KEY --project hasalon-dev
npx firebase deploy --only functions --project hasalon-dev
```

⚠️ **ופונקציה אינה נפרסת מהקונסולה.** עד כה הכל נעשה בהדבקה, **וזה הדבר
הראשון שדורש CLI.**

**2. ו-`GEMINI_API_KEY` ב-Netlify אינו בשימוש יותר.** אפשר להסיר אותו.

**3. `firebase.json` עודכן**, והוא קובץ יסוד. **הבלוק שנוסף:**

```json
"functions": [{ "source": "functions", "codebase": "default",
                "ignore": ["node_modules", ".git", "*.log"] }]
```
