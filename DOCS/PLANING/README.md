  מחוברת אליו:** הקוד נושא חודש, והבדיקה חודשית.
- **מה שרלוונטי לפעילות כולם, ומה שרלוונטי לדוחות מנהלים.** תפוסה והחלפות
  לכולם, **ודירוג של אנשים למנהלים.**
- **לוח עברי ב-`Intl` המובנה, בלי ספרייה**, רשומה
