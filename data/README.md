## איך מייצרים את השניים החסרים

**בהרצה אחת, מהגיליון שבעל המוצר מחזיק:**

```bash
pip install openpyxl
python3 tools/extract-2026-sheet.py <גיליון.xlsx> data
```

**שלושת הקבצים נוצרים יחד**, והסקריפט מדפיס את הסכומים ואת הממצאים. אם המספרים
אינם 214 שיבוצים ו-125 ימי פעילות, **הגיליון אינו אותו גיליון**, רשומה
[01](../DOCS/PLANING/01-the-spreadsheet-as-it-is.md).

## מה יש ב-`summary-2026.json`

- `totals` ו-`byMonth`: הסכומים, ופילוח לכל אחד מעשרת החודשים.
- `shiftTemplates`: **שתיים, `10:00-14:00` ו-`18:00-22:00`.** זו הראיה לכך
  שהתבניות זהות בכל החודשים.
- `weekdaysUsed`: **חמישה, ראשון עד חמישי.** הראיה לכך שאין שישי ושבת.
- `spaces`: התפלגות החללים.
- `findings`: **16 הפערים במלואם.** ⚠️ אלה תאריכים ולא שמות, ולכן הם עוברים.
- `assignmentsPerPseudonym`: כמה משמרות לקח כל אדם, תחת כינוי.

⚠️ **הכינוי אינו אנונימיזציה.** מי שמחזיק את הגיליון יכול לגבב שם ולמצוא אותו.
**הוא קיים כדי שההתפלגות תהיה נראית, לא כדי להסתיר.**
