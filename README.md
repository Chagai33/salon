## ההכרעות שניתנו, 04/10/2026

**עשרים וארבע בחמישה סבבים**, כולן ב-[CLAUDE.md](CLAUDE.md). Firestore, התחברות ב-Google,
התראות מייל בלבד, והמנהל מגדיר את הקוד והאפליקציה מציגה אותו רק למי שזכאי.
**והנוקבות שבהן:**

**השיבוץ מזכה, והנוכחות נמדדת ואינה מזכה.** רדום הוא שלושה חודשים בלי משמרת.
חבר רואה את כולם, **ו"מי לא הגיע" למנהלים בלבד.** הפיד ליומן בלי שמות.
ובהחלפה, **מי שמצא מחליף שומר על הזכאות שלו.**

**חבר נרשם ב-Google וממתין לאישור מנהלת.** ⚠️ **ואין קשר לגיליון: מתחילים
מחדש**, והייבוא מביא ימי פעילות וחגים בלבד.

## הרצת ההמרה

```bash
pip install openpyxl
python3 tools/extract-2026-sheet.py <גיליון.xlsx> data
```

מייצר שלושה קבצים ב-`data/`, ומדפיס את הסכומים ואת הממצאים.

⚠️ **המאגר הזה ציבורי, ולכן הגיליון ושני קובצי הנתונים אינם בו.** שיבוץ הוא
שם של אדם ועוד מקום ועוד שעה, ואף אחד מהאנשים לא נשאל. מה שכן במאגר הוא
`data/summary-2026.json`, אותן מדידות בלי שום שם.
[רשומה 08](DOCS/PLANING/08-the-repository-is-public.md).

## ⚠️ מה שהמדידה מצאה, ולמה המוצר נבנה

**יום שיש בו פעילות מסומן בגיליון בשלושה מקומות שנכתבים ביד:** כוכבית ליד
מספר היום, צבע התא, ושורה ברשימה שבצד. **אין ביניהם שום קשר בקובץ, והם נסתרו
ב-16 מקרים.** חודש יוני כולו חסר כוכביות על אחת עשרה שורות, וכיפור אינו מסומן.

**במוצר העובדה הזו נשמרת פעם אחת, ושלושת הסימונים נגזרים ממנה.**

⚠️ **והממצא הגדול יותר: חצי מהמשמרות ב-2026 לא שובצו כלל.** 214 מתוך 432.
באוגוסט 16% פתוחות, ובשאר החודשים בין 30% ל-67%. **וזה המספר שהדאשבורד קיים
בשבילו**, [רשומה 09](DOCS/PLANING/09-reports-and-the-dashboard.md).

**ו-42 שמות גולמיים הם פחות אנשים**, כי השם הוקלד ביד בכל תא. **ניסיון איחוד
אוטומטי נוסה ונכשל במדידה:** אות בודדת אחת גרפה 30 מתוך 42 השמות לקבוצה אחת,
[רשומה 05](DOCS/PLANING/05-the-import-needs-a-human-decision.md).
