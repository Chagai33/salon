## ההכרעות שניתנו, 04/10/2026

Firestore. התחברות ב-Google ובמייל עם סיסמה. התראות מייל בלבד בגרסה הראשונה.
המנהל מגדיר את קוד הכניסה והאפליקציה מציגה אותו רק למי שזכאי. האפליקציה היא
מקור האמת לימי הפעילות ומפרסמת פיד ICS. **ובהיקף הראשון נכנס גם ייבוא נתוני
2026 מהגיליון.**

## הרצת ההמרה

```bash
pip install openpyxl
python3 tools/extract-2026-sheet.py <גיליון.xlsx> data
```

מייצר שלושה קבצים ב-`data/`, ומדפיס את הסכומים ואת הממצאים.

⚠️ **המאגר הזה ציבורי, ולכן הגיליון ושני קובצי הנתונים אינם בו.** שיבוץ הוא
שם של אדם ועוד מקום ועוד שעה, ואף אחד מהאנשים לא נשאל. מה שכן במאגר הוא
`data/summary-2026.json`, אותן מדידות בלי שום שם.
[רשומה 08](DOCS/PLANING/08-the-repository-is-public.md).

## ⚠️ מה שהמדידה מצאה, ולמה המוצר נבנה

**יום שיש בו פעילות מסומן בגיליון בשלושה מקומות שנכתבים ביד:** כוכבית ליד
מספר היום, צבע התא, ושורה ברשימה שבצד. **אין ביניהם שום קשר בקובץ, והם נסתרו
ב-16 מקרים.** חודש יוני כולו חסר כוכביות על אחת עשרה שורות, וכיפור אינו מסומן.

**במוצר העובדה הזו נשמרת פעם אחת, ושלושת הסימונים נגזרים ממנה.**

**ו-42 שמות גולמיים הם פחות אנשים.** אותו אדם נכתב בשם מלא, בשם ועוד ראשית שם
משפחה, ובראשית שם ועוד שם משפחה.

⚠️ **ואי אפשר לאחד אותם בקוד.** שתי נשים שונות חולקות שם פרטי, והשם הנפוץ
ביותר בגיליון הוא גם שם המשפחה של אחת מהן. **ניסיון איחוד אוטומטי נוסה ונכשל
במדידה:** אות בודדת אחת גרפה 30 מתוך 42 השמות לקבוצה אחת.
